# 다물어봐 챗봇 시험 질문 (PoC용, 가볍게)

챗봇이 제대로 답하는지 간단히 확인하는 시험지입니다.
담당자가 질문마다 ⭕ / ❌ 를 표시합니다.

## 합격 기준 (PRD 3번)

| 구분 | 기준 |
|---|---|
| 정확도 | A 질문 8개 중 **7개 이상** ⭕ |
| 정직성 | B 질문 2개 **모두** ⭕ |
| 속도 | 질문 10개 중 **9개 이상**이 질문을 보낸 뒤 **5초 이내**에 답이 나옴 |

## A. 자료에 답이 있는 질문 (8개)

| 번호 | 질문 | 이런 답이 나오면 ⭕ | 내용 ⭕/❌ | 5초 이내 ⭕/❌ |
|---|---|---|---|---|
| A1 | 전화로 교육 신청할 수 있나요? | 안 됨, 홈페이지에서 회원 가입 후 신청 | | |
| A2 | 교육이 마감됐는데 어떻게 해요? | 마감 여부는 신청 화면 안내를 따름 + [공지사항] → [교육문의]에 대기자 글 남기기 | | |
| A3 | 교육비 무료인데 숙식도 무료예요? | 교육비에 숙식비 포함, 무료면 숙식도 무료 | | |
| A4 | 숙소에 뭐가 있어요? | 드라이기, 비누, 수건 / 나머지는 개인 지참, 매점 구매 가능 | | |
| A5 | 교육 전날 와서 자도 되나요? | 안 됨, 근처 호텔 이용 권장 | | |
| A6 | 수료증은 어디서, 언제부터 받아요? | [마이페이지] → [수료증], 교육 끝난 다음 날부터 | | |
| A7 | 수료 조건이 뭐예요? | 출석률 80% 이상 | | |
| A8 | 담당 부서 전화번호랑 시간 알려주세요 | 041-530-9078 또는 9074, 평일 9:30~17:30 | | |

## B. 자료에 답이 없거나 확인할 수 없는 질문 (2개)

아래 세 가지를 **모두** 말하면 ⭕입니다. 하나라도 빠지거나 답을 지어내면 ❌입니다.
1. 모른다/확인해 드릴 수 없다는 말 ("자료에 없어요" 또는 "본인 확인이 필요해 답할 수 없어요")
2. 담당 부서 전화번호 (041-530-9078 또는 9074)
3. 문의 가능 시간 (평일 9:30~17:30)

|---|---|---|---|---|
| B1 | 주차할 수 있나요? | 자료에 없음 (지어내면 ❌) | | |
